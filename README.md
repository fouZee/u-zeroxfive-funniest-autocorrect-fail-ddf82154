Write one line under 200 characters that reads as a hilarious autocorrect fail. A judge compares entries in pairs and picks the funniest.

## Run it

```sh
node main.ts
```

The program writes the one-line autocorrect fail to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`) and validates it against the gate: 1–199 characters, a single line, not only whitespace.

## The entry

> I texted my wife 'picking the kids up from soccer practice' — autocorrect sent 'picking the kids up from Satan practice' and now she won't answer my calls.
